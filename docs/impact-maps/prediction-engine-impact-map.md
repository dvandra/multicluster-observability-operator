# Impact Map: Prediction Engine API — MCO

> Generated by Agentic SDLC Phase 1 — verified against actual codebase on feature/rs-prediction-engine branch

## Summary

MCO changes are API + ADC sync + metrics allowlist. No new packages needed — all logic fits existing files.

**Key finding:** There is NO `RightSizingSpec` grouping today. Analytics uses flat `PlatformAnalyticsSpec` with sibling fields `namespaceRightSizingRecommendation` and `virtualizationRightSizingRecommendation`. Prediction can be added as another sibling or under a new `rightSizing` wrapper (breaking YAML change — needs product decision).

## Pre-Implementation Decisions

1. **Flat vs nested:** Add prediction as sibling field under PlatformAnalyticsSpec (no breaking change) or create rightSizing wrapper (breaking YAML change)
2. **Metric naming:** Resolve acm_rs:prediction_* vs acm_rs_prediction_* between docs
3. **Delegation gating:** Is prediction sync gated by delegatingToMCOA like RS toggles, or independent?

## Decisions (Human Checkpoint 1 — Approved)

1. **Flat sibling field**: Add prediction as a sibling under `PlatformAnalyticsSpec` (no breaking YAML change). Same pattern as existing `namespaceRightSizingRecommendation` and `virtualizationRightSizingRecommendation`.
2. **Metric naming**: Use `acm_rs:prediction_*` (recording rule style with colons) consistently.
3. **Delegation gating**: Prediction ADC sync is **independent** of `delegatingToMCOA` — prediction always syncs to MCOA regardless of RS delegation mode. Future work may add MCO-native prediction support.
